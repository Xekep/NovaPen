# NovaPen 1.0.1 RC3

Исправление рисования на нескольких мониторах с разным масштабом Windows.
RC2 отозван; его публикация и тег удалены.

- Исправлено смещение штрихов относительно курсора на дополнительных мониторах. Для каждого окна слоя согласованы нативный DPI, масштаб рендеринга и физические координаты ввода. Системные настройки масштаба не меняются.
- Исправлены увеличение слоя после скрытия/показа и обрезание рисования у дальнего края экрана. Размер и положение слоя соответствуют физическим границам его монитора.
- Новая проверка проходит каждый доступный монитор: сравнивает координаты с Win32, проверяет фактически нарисованный пиксель, границы слоя и повторный показ окна. Локально на трёх мониторах с масштабами 100% и 125% прошли по 12 проверок в обычном и принудительном программном режиме Native AOT; измеренная ошибка координат — 0 пикселей. Также прошли Managed smoke и сборка решения без ошибок и предупреждений.
- Сохранён переход на стабильный .NET 11 / SDK 11.0.100 и исправлена согласованность имён Debian RC-пакетов с файлами контрольных сумм на GitHub.

**Распознавание остаётся экспериментальным.** Перенос движка, русский и английский слитный почерк, автоматическое определение содержимого и применение повторного математического результата ещё не завершены. Этот выпуск не заявляет улучшения точности распознавания.

Сохраняются известные численные расхождения экспериментального Math2 на macOS и отдельные различия повторных диагностических результатов на Linux с .NET 10.0.15; их причина ещё исследуется, проверки не ослаблены. Две диагностики Avalonia DirectComposition при Windows Native AOT также остаются.

Платформенные архивы и установщики публикуются после успешного завершения всех заданий Release. Это предварительная версия; стабильный канал остаётся на 1.0.0.
