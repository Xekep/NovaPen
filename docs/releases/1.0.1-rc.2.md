# NovaPen 1.0.1 RC2

Предварительный выпуск после перехода на стабильный .NET 11.

- Приложение и сервер используют .NET 11; сборки закреплены на SDK 11.0.100 без prerelease SDK.
- Сохранена полная сборка ресурсов Avalonia при Native AOT. Проверка изменения размера штриха корректно переводит координаты на экранах с разным DPI; проверка исчезающих штрихов дожидается настоящего фонового таймера.
- Обновлены проверки страницы скачивания: выбор языка сохраняется отдельно, код приглашения не отправляется в запросах и не записывается в хранилище.
- В экспериментальном математическом движке добавлены переназначение тегов поддеревьев и проверка структурных изменений на копии дерева. Локально прошли 121 проверка ядра, 886 проверок на реальных моделях в Managed и Native AOT, независимые проверки и 13 проверок повреждённых данных.
- Windows-проверка CAS использует тот же Giac, собранный из закреплённых исходников, что и приложение, вместо изменяемого внешнего установщика.

**Перенос движка не завершён.** Применение повторного результата к исходному документу, откат, русский и английский слитный почерк и автоматическое определение содержимого ещё дорабатываются. Этот RC не заявляет улучшения точности распознавания.

На macOS сохраняется известное отличие экспериментального Math2 от замороженного Windows-эталона. В отдельном диагностическом прогоне на Linux с .NET 10.0.15 также обнаружено различие повторных результатов; изолированный прогон с .NET 10.0.12 воспроизвёл точное совпадение Managed/повтора/Native AOT. Причина расхождения пока не установлена, числовые проверки не ослаблены. Две диагностики Avalonia DirectComposition при Windows AOT также остаются.

Архивы и установщики публикуются только после успешного выполнения платформенных заданий Release. Стабильная версия 1.0.0 остаётся доступна; RC не заменяет её в канале стабильных обновлений.
